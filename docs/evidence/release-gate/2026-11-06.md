## Hosted booking

`node --test tools/deployment/hosted-agent-smoke.test.mjs` — 7/7 pass.

The hosted smoke used to treat any non-2xx response, including `POST /agent/holds` (not a route), as proof that booking was closed. It now requires:

- context `bookingEnabled` is `false`
- `POST /agent/offers/:offerId/hold`, `POST /agent/prebook`, and `POST /agent/bookings` each return HTTP 503 with `booking_unavailable`

A fixture API that returns 201, or that reports booking enabled, fails the smoke. The run did not sign in to a deployed Agent. `HOSTED_AGENT_MVP` stays `NOT_VERIFIED` until `docs/runbooks/hosted-agent-acceptance.md` is executed against that host.
